# Kit 1 · The instructions for your assistant

Copy each one exactly. Replace only the parts in [square brackets].

They work in any assistant that reads text you paste in. Start a new chat each week, unless you saved Instruction 0 as a standing instruction (step 1).

---

## Instruction 0 · The standing brief

Paste once (step 1), with Sheet A at the end.

```
You are my content assistant. You help me turn one
recording or one post of mine into posts for the
platforms I use.

Rules you always follow:
1. Use my words and my examples. Never invent a
   story, a client, a number, a result or a quote.
2. If a piece needs a fact you do not have, write
   [CHECK] where it goes and tell me what is missing.
3. Never promise a result, an income, or a time to
   get a result.
4. Write the way I talk: short sentences, plain
   words. Never use the words on my never list.
5. One idea per piece.
6. When I ask for a number of options, give exactly
   that number.
7. Label every piece: platform / angle / source.

Reply "Ready" and one sentence on who I serve.

SHEET A:
[paste Sheet A here]
```

---

## Instruction 1 · Core ideas and angles

Step 4. Paste with the text of this week's source.

```
Here is this week's source. Its name is [source name
from Sheet C].

Find 3 core ideas in it. A core idea is one problem
my buyer has, said in one sentence, that this source
answers.

For each core idea, give 4 angles. An angle is a
different side of the same problem: a mistake people
make, a question people ask, a before and after, a
myth, the steps, or a story from the source.

Under each angle, quote the lines of the source it
comes from.

Do not write any posts yet.

SOURCE:
[paste the text here]
```

---

## Instruction 2 · The pieces

Step 5. Paste after you pick the core idea.

```
Core idea: [the one I picked]
Angles: [the 4 angles of that idea]

My platforms and weekly set:
[paste Sheet B]

For each angle, and each platform on Sheet B, write
one piece in the format I use on that platform. Stop
at the number of pieces Sheet B sets for each
platform.

For each piece give:
- 5 opening lines to choose from, each under 15
  words
- the body, in my words, at the length I use there
- the call to action Sheet B sets for that platform
- the label: platform / angle / source

Use only the source and Sheet A. Write [CHECK] for
any fact that is not in them.
```

---

## Instruction 3 · The long version and the question

Step 5.

```
Now write one long version of this week's core idea,
for [my newsletter / a LinkedIn article / my blog /
my YouTube description: pick one].

Then write one qualifying question: a yes or no
question my buyer can answer to see if they have
this problem. Put it at the end of the long version,
just before the call to action.

Same rules: my words, no invented facts, [CHECK]
where a fact is missing.
```

---

## Instruction 4 · The clip list (video sources only)

Step 5. Works best when your text has times in it.

```
This source is a video. For each angle, list one
clip: the start time, the end time, the first
sentence and the last sentence.

Each clip runs 20 to 60 seconds, starts on a full
sentence and ends on a full sentence. Do not change
my words. If the text has no times, give only the
first and last sentence and I will find them.
```

---

## Instruction 5 · The self-check

Step 5, after every piece is written.

```
Check every piece you wrote this week. List, piece
by piece:
1. every number, name, result, quote or claim, with
   the source line it came from, or NOT IN SOURCE
2. every [CHECK] still open
3. any word from my never list
4. any promise of a result, an income or a time

Then list the pieces that have nothing to fix.
```

---

## Instruction 6 · The Friday read

Step 7. Paste with this week's Sheet E and the last three weeks of Sheet F.

```
Here is my posting log for this week, and my
scorecard for this week and the two weeks before.

Tell me:
1. which 2 pieces on the posting log brought the
   most comments and enquiries together, and what
   their opening lines had in common
2. which platform brought enquiries this week, and
   which brought none in all 3 weeks
3. three ideas for next week's source, each tied to
   a question on this week's enquiry list

Use only what is on the sheets. Do not guess. If a
box says UNKNOWN, or I pasted fewer than 3 weeks,
say what you cannot tell.

POSTING LOG:
[paste Sheet E, this week]

SCORECARDS:
[paste Sheet F, the last three weeks]
```
